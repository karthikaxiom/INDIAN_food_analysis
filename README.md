# Indian Food Analysis using Data Analytics

## Project Overview

Indian Food Analysis is a data analytics project that explores the characteristics of various Indian dishes using Exploratory Data Analysis (EDA) and data visualization techniques. The objective of this project is to analyze the dataset, identify meaningful patterns, and gain insights into Indian cuisine based on ingredients, preparation time, cooking time, dietary preferences, and regional diversity.

The project demonstrates the use of Python and data science libraries to clean, analyze, and visualize real-world data.

---

## Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Statistical analysis of the dataset
- Analysis of vegetarian and non-vegetarian dishes
- Ingredient frequency analysis
- Preparation and cooking time analysis
- Cuisine and regional analysis
- Data visualization using charts and graphs

---
## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset contains information about Indian food dishes, including:

- Dish Name
- Ingredients
- State/Region
- Diet Type
- Course
- Preparation Time
- Cooking Time
- Total Time
- Flavor Profile
